# Generated experimental plugin

This plugin is a packaging adapter for the canonical `readme-review` and
`readme-generate` capabilities in `k421o/readme-labs`.

- Maturity: experimental
- Version: `0.3.0-dev.1`
- Marketplace status: repository-owned local/Git marketplace; not a public or
  verified listing
- Editable sources: `capabilities/readme-review` and
  `capabilities/readme-generate`
- Generation record: `UPSTREAM.json`

Do not edit generated directories under `skills/` directly. Run
`scripts/build_plugin.py` from the repository root and validate the result
before use.
