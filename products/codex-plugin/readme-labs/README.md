# Generated experimental plugin

This plugin is a packaging adapter for three canonical capabilities in
`k421o/readme-labs`:

- `readme-review` for evidence-backed findings;
- `readme-generate` for creation or explicit replacement; and
- `readme-prune` for preservation-aware subtraction.

- Maturity: experimental
- Version: `0.3.0-dev.2`
- Marketplace status: repository-owned local/Git marketplace; not a public or
  verified listing
- Editable sources: the matching directories under `capabilities/`
- Generation record: `UPSTREAM.json`

Do not edit generated directories under `skills/` directly. Run
`scripts/build_plugin.py` from the repository root and validate the result
before use.
