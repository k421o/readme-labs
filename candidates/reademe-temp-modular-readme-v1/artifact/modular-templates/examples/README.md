# Assembly Examples

These files demonstrate how independently selected modules fit together. They intentionally retain placeholders and are not finished project READMEs.

- [Minimal README](minimal-readme.md): title, short description, usage, and license.
- [Reusable-library README](assembled-library-readme.md): a fuller example with navigation, installation, API, and governance.
- [Module selection worksheet](module-selection-worksheet.md): a decision record to complete before assembly.

Copy selected fragments from the atomic module guides rather than treating an example as the canonical template. The modules contain the applicability rules and validation checks that the examples omit.
