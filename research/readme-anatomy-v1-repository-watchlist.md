# README anatomy, version 1: repository watchlist

Research snapshot: 2026-08-29

This exploratory companion to [`readme-anatomy-v1.md`](readme-anatomy-v1.md)
records repositories the user finds interesting or identifies with. Inclusion
does not mean that a repository's README is authoritative, exemplary,
well-structured, representative, or especially prevalent in model-training
data.

Keep this watchlist separate from
[`readme-anatomy-v1-sources.md`](readme-anatomy-v1-sources.md). Promote a
repository to the evidence-backed source list only after reviewing its README,
identifying the specific pattern it demonstrates, and recording why that
pattern is useful.

## Questions for a later review

For each repository, record:

1. What role the README actually serves: package page, application landing
   page, release index, curated list, source-tree guide, or another role.
2. How quickly its opening establishes identity, purpose, and audience.
3. What it treats as the reader's first successful action.
4. Which detail remains local and which detail routes to canonical
   documentation.
5. Which project-specific constraints or boundaries it makes prominent.
6. What is distinctive or personally resonant, even if it should not become a
   general recommendation.
7. Whether the observed pattern belongs in the anatomy, the source list, a
   role-specific example set, or only this watchlist.
